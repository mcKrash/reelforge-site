Privacy policy

Last updated: 14 November 2026

reelforge is a personal tool used only by its owner to upload videos it generates to the owner's own YouTube channels.

What it accesses

With the owner's permission, it uses the YouTube Data API scope youtube.upload, only to upload videos to the owner's channels. It does not read, collect, store or share any data about viewers or any other people.

What it stores

The sign-in token is stored privately on the owner's own server and is used only to upload. Nothing is sold or shared with anyone.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
